Open DesignDesk AI

What comes from the live site

  • Product names, categories and links to every product page
  • From-prices for bestsellers and full price tables for A5 flyers (10 to 1,000) and matt laminated business cards (100 to 10,000)
  • Print specification: PDF preferred, 300dpi, 3mm bleed, 5mm safe zone, CMYK or RGB converted
  • Trimmed sizes, e.g. A5 148 × 210mm and business cards 85 × 55mm
  • Delivery: order and approve by 1pm for next day, 2–3 working days for larger runs, free delivery

How the AI is simulated here

  • The POC runs entirely in the browser so it works offline and can be shared as one file
  • Chat replies, data extraction and copywriting use rules written against the real catalogue; in the build these calls go to the AI model through the WordPress REST API
  • PreFlight measures real files: pixel size, effective DPI, bleed, JPEG colour mode, PDF page boxes and embedded fonts
  • DesignDesk exports a genuine PDF with TrimBox and BleedBox set

    File processing server
    
          
    Uploads go to a processing server. Each file runs through the same pipeline before the vision model looks at the rendered page.
    
          
    # 1. Page boxes and page count (Poppler)
pdfinfo -box artwork.pdf

# 2. Fonts: every font must show "emb yes"
pdffonts artwork.pdf

# 3. Ink coverage per page (Ghostscript)
gs -q -o - -sDEVICE=inkcov artwork.pdf

# 4. Render a preview at 150dpi for the vision model
gs -q -o page-%d.png -sDEVICE=png16m -r150 artwork.pdf

# 5. Raster files: size, density and colourspace (ImageMagick)
identify -format "%w %h %x %y %[colorspace]\n" artwork.jpg
    
        
    
        
    
          
    AI vision checks
    
          
    The rendered preview goes to the vision model with the product’s trim and safe area. It returns structured findings that are drawn on the overlay.

  "spelling": [{ "found": "Recieve", "suggest": "Receive" }]
